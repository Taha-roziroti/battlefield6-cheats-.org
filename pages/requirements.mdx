# Battlefield 6 Cheat Requirements for Windows PC

General Battlefield 6 requirements plus extra items for Cloud DMA and the HWID utility.

## Core Windows requirements

Windows 10 or 11 (Intel or AMD). HVCI, Core Isolation, TPM, and Secure Boot must be enabled per the current setup notes.

## HVCI, Core Isolation, TPM, and Secure Boot

Confirm each item against your edition and firmware before install—do not toggle several security features at once without the published steps.

## Additional Cloud DMA requirements

Windows 10/11 64-bit, VT-x or AMD-V in firmware, Hyper-V role, 8 GB RAM minimum (16 GB recommended), and stable broadband. See the [Cloud DMA guide](/cloud-dma/).

## HWID spoofer setup requirements

Windows 10/11 64-bit, administrator rights, stable internet, and the same security settings. Details on the [HWID spoofer page](/battlefield-6-hwid-spoofer/).

## A quick pre-setup checklist

Version, CPU platform, security flags, and internet—plus virtualization and RAM if you chose Cloud DMA. Then open [cheats overview](/), [aimbot](/battlefield-6-aimbot/), or [ESP](/battlefield-6-esp/).

## Frequently asked questions

### Which Windows versions are listed for Battlefield 6 software?

Windows 10 and Windows 11 on supported Intel and AMD systems.

### Do Cloud DMA and the main feature set share identical requirements?

No—Cloud DMA adds Hyper-V, virtualization, and memory requirements beyond the core checklist.

### Where are aim and ESP settings documented?

[Battlefield 6 aimbot](/battlefield-6-aimbot/) and [Battlefield 6 ESP](/battlefield-6-esp/).
